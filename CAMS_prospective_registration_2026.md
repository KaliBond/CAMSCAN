# CAMS Prospective Registration — Live Cases (registered 2026-08-30)

## Purpose

This document registers falsifiable, dated predictions for three live cases —
**USA, Japan, South Africa** — *before* the next scoring pass extends their
series. The point is to remove hindsight bias from validation: predictions
below are locked at time of writing (last known data point: USA/Japan/South
Africa unified series and blind-set results as of Session 3, dataset
`JUNO_Unified_Dataset.csv`). A future scoring run (blind where possible)
either confirms or falsifies each numbered claim. Do not revise these claims
after seeing new data — append a dated resolution note instead.

Each case gets: (a) the established baseline it extrapolates from, (b)
numbered falsifiable predictions with explicit thresholds, (c) the specific
test that would falsify each one, (d) what would count as contamination
(scorer artifact) vs. genuine signal where relevant.

## USA

**Baseline (established, do not re-derive):** System V in freefall
2019–2025 (10.4 → 4.7 ensemble; unified series 15.6 → 3.6 for 1945→2026).
Terminal V is already below the 1930 Depression trough (4.6) — a first.
AR1 (critical-slowing-down indicator) ramping at 0.57. Resolution-organ
history: Helm-led recovery 4× (1932–1980), then switched to Flow in 2008 —
flagged as fateful. Shield is stress-insulated (stress gap 1.9 vs 0.1 for
other nodes). Mythic–metabolic coupling (Lore vs Stewards+Craft+Hands) in
secular decline since the 1960s break, ~0.72 by 2000, and not
decoupling-driven in the strict H5 sense — this is slow co-decline, not a
clean decoupling collapse.

**Predictions for the next scoring extension (through ~2028–2030):**

1. **No Helm-led recovery re-emerges.** The dominant resolution organ for
   any USA rebound in 2026–2030 will *not* be Helm (breaking the
   1932–1980 pattern). Falsified if a new crisis trough is followed by a
   5-year Helm-led recovery matching the historical signature.
2. **V does not recover above 6.0 by 2028** without a visible regime-level
   intervention (a scored discontinuity in Helm Coherence/Capacity, not
   just Flow). Falsified if ensemble V for the USA system exceeds 6.0 in
   any year 2026–2028 while Flow remains the lead node.
3. **AR1 crosses 0.65 by 2028** if no structural intervention occurs
   (continuing the 0.57 ramp toward the ~0.7–0.8 range that preceded
   Japan's endogenous pre-1998 decline). Falsified if AR1 plateaus or
   falls back below 0.5.
4. **Shield stays insulated.** The Shield stress-gap advantage (currently
   ~1.9 vs ~0.1 elsewhere) persists even as Stewards/Craft/Hands continue
   to erode — i.e., Shield does not co-degrade with the rest of the
   system through 2030. Falsified if Shield's stress gap collapses to
   parity with the other nodes.
5. **Lore–metabolic coupling stays below 0.80** through 2030 absent a
   unifying mythic/narrative event (e.g., a war-scale mobilization).
   Falsified if coupling recovers above 0.80 without such an event.

## Japan

**Baseline (established):** Lucid-dreamer profile — highest dream score,
Shield leads both dream and wake registers. Shield-conserved: V ≈ 20 held
essentially flat across all regimes 1900–2010 (imperial, wartime, occupied,
pacifist, stagnant) — read as "coercive recoordination," explicitly *not*
a militarist-stereotype artifact. Archive is the resolution organ through
the stagnation decades and shows up as the always-leading recovery node.
Pre-1998 critical slowing down was real and endogenous: AR1 0.29 → 0.80.
This is the project's flagged **contamination-vs-insight test case**: is
Shield's near-invariance a genuine conserved organ, or an LLM-ensemble
artifact (i.e., scorers defaulting to a stereotyped "Japan = disciplined/
orderly" prior regardless of actual evidence)?

**Predictions:**

1. **Shield stays in the ~18–22 band through the next extension
   (2010–2026)**, essentially flat despite Japan's real economic and
   demographic stress over that period. This is the headline prediction —
   confirming it is *consistent with* either conserved-organ signal or
   artifact (it doesn't discriminate on its own; see test below).
2. **Discriminating test:** re-score 2010–2026 using a *structurally
   independent* prompt/ensemble path (e.g., camnationsm5n-style multi-agent
   blind scoring with no visibility into prior Japan scores or this
   document). If Shield still lands in the 18–22 band under that blind,
   independent pass, treat it as evidence for genuine conserved-organ
   signal. If independent scorers instead disperse widely on Shield, or
   only converge near 20 when told it's Japan, that is evidence for
   stereotype-driven contamination. This is the single most important
   falsification test in the current CAMS validation program — flag any
   result either way.
3. **Archive continues to lead recovery** from any new perturbation
   scored in 2010–2026 (economic stress, demographic crisis, disaster
   response), continuing the "Archive-always" resolution-organ pattern.
   Falsified if a different node (e.g., Flow or Stewards) leads a 5-year
   post-trough recovery instead.
4. **AR1 remains elevated (>0.6) rather than resetting**, consistent with
   a continuing slow-bleed endogenous dynamic post-1998 rather than a
   sharp exogenous shock profile. Falsified if AR1 drops back toward
   pre-1990s levels (<0.4) without an intervening shock.

## South Africa

**Baseline (established):** Terminal decline to 2025 (Blind Set 2, series
C). No resolution-organ signature has yet been established for South
Africa in this project — that is itself an open question, not a settled
result. This case has the thinnest established baseline of the three, so
predictions here are more exploratory and some are framed as open
questions to be answered by the next pass rather than point predictions.

**Predictions / questions to resolve:**

1. **Decline continues through 2026–2030** absent a new resolution organ
   emerging — i.e., no node stabilizes and leads a 5-year recovery in the
   next extension. Falsified if any node (Helm, Stewards, Flow, etc.)
   shows a clear post-trough lead consistent with the resolution-organ
   pattern seen elsewhere.
2. **Open question (not a prediction):** which node, if any, becomes
   South Africa's resolution organ? Every other scored society in this
   project (Germany→Flow, USA→Helm→Flow, Thailand→Archive, Japan→Archive,
   Russia→Helm→Hands→Shield, China→never repeats) has a characterizable
   pattern. If South Africa's next extension shows no consistent
   resolution organ at all, that is a genuine and notable finding (a
   "no stable resolution organ" class), not a data gap — flag it as such
   rather than defaulting to "insufficient data."
3. **If critical-slowing-down (EWS) signal is present**, expect it to
   show up first in Stewards and/or Hands (the nodes most exposed to
   South Africa's known stress channels — infrastructure/service
   provisioning and labour) ahead of any further scored crisis event.
   Falsified if EWS signal instead concentrates in Helm/Shield with
   Stewards/Hands comparatively stable.
4. **Brazil-flatness cross-check:** since Brazil's flat response to
   coups/regime changes is flagged as unresolved (real shallow
   differentiation vs. thin-corpus artifact — item 9 in prior results),
   check whether South Africa's terminal decline shows similarly flat,
   low-variance transitions around known regime-relevant events (e.g.,
   post-2008 political transitions, load-shedding-era governance
   crises). If South Africa *also* shows flat transitions, that
   strengthens the "thin-corpus artifact" reading for both; if South
   Africa shows sharp transitions where Brazil doesn't, that argues
   Brazil's flatness is a real, case-specific finding rather than a
   general corpus artifact.
